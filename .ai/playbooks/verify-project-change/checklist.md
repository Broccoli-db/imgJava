# 验证选择清单

## 基线

- `git diff --check`
- 复核 `git status --short` 和实际 diff
- 检查 secret、调试输出、生成物和意外的构建文件变化

## 构建与依赖

- 构建文件可解析，包装器与项目一致（`./mvnw` 或 `./gradlew`）
- 依赖声明与项目的版本管理方式一致，没有快照版本意外进入发布产物
- 新依赖必要且与项目 JDK 版本兼容
- 构建插件没有引入任务外的代码生成或副作用

## API

- 输入校验和状态码
- 错误结构与统一异常处理
- 认证、授权、限流、CORS 和敏感信息
- 成功、非法输入、冲突、依赖失败和超时

## 数据库

- 迁移可在空库和现有 schema 上执行
- 约束、索引、事务边界和部署顺序
- 查询参数化、分页和并发路径
- 回滚或恢复策略

## 并发/任务

- 异步异常处理、超时、取消和重试
- 并发上限、重复消息和幂等性
- 关闭流程下停止接收并释放资源

## 配置和 Guard

- 配置缺失、非法值和生产默认值
- Windows/POSIX 路径、大小写和分隔符
- Guard 的允许、拒绝、误拦和绕过用例
