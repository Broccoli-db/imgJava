# 通用 AI 项目运行层

`.ai/` 保存不依赖具体厂商的工程知识和工作流程。工具是否自动加载这些文件取决于其自身能力；统一入口始终是根目录 `AGENTS.md`。

| 路径 | 职责 | 更新频率 |
|---|---|---|
| `CORE.md` | 安全红线和基本行为 | 极低 |
| `ARCHITECTURE.md` | 稳定架构、集成点和已知坑 | 低 |
| `CHECKLIST.md` | 完成前质量闸门 | 低 |
| `SESSION.md` | 当前任务状态，本地忽略 | 每次任务 |
| `rules/` | 按技术领域选择加载的专项规则 | 按需 |
| `workflows/` | 可复制给任意 AI 工具执行的工作流 | 按需 |
| `playbooks/` | 多步骤验证手册 | 按需 |
| `roles/` | 可用于主代理或子代理的角色提示 | 按需 |
| `guards/` | 可被支持 Hook 的工具调用，也可独立运行的保护脚本 | 按需 |

## 规则仲裁

平台/系统安全约束优先于用户指令；用户明确授权优先于项目内部规则；项目内部按红线、约定、偏好排序。同级冲突取更具体、更新且与当前路径更相关的规则。

## 配置所有权

团队配置提交到 `AGENTS.md`、`AI.md` 和 `.ai/`。个人配置放在被忽略的 `AI.local.md`、`.ai/SESSION.md` 或 `.ai/local/`。任何位置都不得保存凭据。

## 任务起止

- 小改动：读取入口、目标文件和匹配规则，执行目标检查。
- 普通功能：再读取架构、最近记录和相关测试，更新记录与 SESSION。
- 高风险改动：完整检查认证授权、数据库、并发、兼容性、回滚和失败路径。
- 只读审查、总结和纯验证任务不修改 SESSION 或改动日志。
