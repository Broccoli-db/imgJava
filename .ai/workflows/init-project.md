# 工作流：初始化 Java 项目规则

把本文件内容作为任务交给当前 AI 工具执行。

1. 读取 `pom.xml` 或 `build.gradle`、构建包装器、JDK 与工具链配置、应用入口、配置绑定类、迁移目录、测试和 CI 文件。
2. 识别真实技术栈、包结构、构建工具、命令、服务边界和数据存储。
3. 补全 `AGENTS.md`、`AI.md`、`PROJECT.md`、`.ai/CORE.md`、`.ai/ARCHITECTURE.md`、`.ai/rules/` 和 `docs/` 中的 `{{...}}` 与 `[待补全]`。
4. 删除不适用于项目的规则，不要保留虚假的框架、数据库、认证或测试约定。
5. 无法从代码或正式文档确认的内容标记为 `[待确认]`，不要猜测。
6. 检查 `.gitignore` 已忽略本地 AI 状态、本地 profile 配置、凭据、构建产物和密钥库。
7. 运行 `java scripts/TestGuard.java`，并验证文档中没有遗留非示例占位符。
8. 在 `docs/记录.md` 顶部追加初始化记录。

最后总结已确认事实、待确认项、命令和外部只读边界。
