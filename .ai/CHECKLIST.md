# CHECKLIST - 完成前质量闸门

只执行与改动风险相匹配的检查，并如实报告未覆盖项。

## 通用

- [ ] `git diff --check` 通过，实际 diff 已复核
- [ ] 没有覆盖无关用户改动，没有 secret、调试日志或意外生成物
- [ ] 使用项目声明的 JDK 和构建包装器，没有混用 Maven/Gradle，没有无关依赖变更
- [ ] 新依赖确有必要，依赖声明与版本管理方式一致
- [ ] `docs/记录.md` 记录实际改动和验证边界（只读任务除外）

## API 与安全

- [ ] 请求参数、路径参数、查询参数、Header 和外部响应已验证（Bean Validation 或显式校验）
- [ ] 成功、非法输入、未认证、无权限、不存在、冲突和依赖失败响应符合契约
- [ ] SQL/JPQL 参数化；动态表名、列名和排序字段走 allowlist；没有命令、路径、模板或反序列化注入
- [ ] 密码、JWT、Session、cookie、CORS、限流和上传策略符合项目要求
- [ ] 日志和错误响应不包含凭据、敏感数据、堆栈或内部实现

## 并发与生命周期

- [ ] 异步结果（`CompletableFuture`/`@Async`）的异常分支已处理，没有静默丢失
- [ ] `InterruptedException` 未被吞掉，中断状态正确传播或在恢复后重新设置
- [ ] 外部调用有超时；并发、重试和消费有上限
- [ ] 共享可变状态有正确的可见性或同步；虚拟线程使用未引入上下文泄漏
- [ ] 重复请求、Webhook 或消息处理具备所需幂等性
- [ ] 启动失败快速退出；关闭过程释放连接池、缓存、消费者和线程池

## 数据库

- [ ] schema 变化有迁移和约束，应用代码与迁移部署顺序兼容
- [ ] 多步写入使用正确事务边界，异常路径会回滚
- [ ] 查询考虑索引、分页、N+1、空结果和并发冲突
- [ ] 破坏性迁移有备份、回滚或分阶段发布方案

## 验证矩阵

| 改动 | 最低验证 |
|---|---|
| 文档/配置模板 | 格式检查 + 占位符检查 |
| 纯重构 | 编译 + 目标单元测试 |
| API/业务逻辑 | 上述 + 集成测试和失败路径 |
| 数据库/迁移 | 上述 + 临时数据库迁移与回滚/恢复验证 |
| 认证/权限 | 有效、无效、过期、无权限和跨资源访问 |
| 并发/定时任务 | 重复、重试、失败、取消、超时和优雅关闭 |
